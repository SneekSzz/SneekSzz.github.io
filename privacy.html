Privacy Policy

Last updated: November 22, 2026

Overview

RS Server Backups is a personal, non-commercial application used to back up a self-hosted game server to Google Drive using Rclone.

Google Drive Access

The application uses Google OAuth to access and manage backup files it creates in the authorized user's Google Drive account.

Data Security

Game server backups are intended to be encrypted locally using Rclone Crypt before uploading. Authentication credentials are stored on the user's private server.

Data Sharing

This application does not sell user information or share backup data with advertisers. Google Drive processes stored files according to Google's applicable policies.

Data Retention and Deletion

Backup files are retained according to the configured backup schedule. The user can delete backups from Google Drive and revoke OAuth access through Google Account settings.
